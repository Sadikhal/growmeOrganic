
# Art Institute of Chicago - Artworks Table

This is a simple React + TypeScript project that displays artworks from the Art Institute of Chicago API using a table with pagination, selection, and basic filtering.

## Features
- Fetch artworks from the Art Institute of Chicago API
- Paginated table using PrimeReact DataTable & Paginator
- Select multiple artworks across pages
- Select first N artworks using overlay input
- Handles null `inscriptions` field with a placeholder "No inscription"

## Tech Stack
- React (TypeScript)
- PrimeReact for UI components
- Axios for API calls
- React Router for search params

## Setup & Run

1. **Clone the repository**

```bash
git clone <your-repo-url>
cd <your-repo-folder>
````

2. **Install dependencies**

```bash
npm install
# or
yarn install
```

3. **Start the development server**

```bash
npm run dev
# or
yarn dev
```

4. **Open in browser**

Visit [http://localhost:5173](http://localhost:5173) (Vite default port)
